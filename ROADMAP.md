# Roadmap

- [x] **1.** One chat room: WebSocket broadcast to everyone connected
   - [x] Display names (typed in, remembered in the browser; real accounts come in milestone 4)
- [x] **2.** Save messages in SQLite and load history when someone joins
- [x] **3.** Channels (#general, #memes, …) and a sidebar to switch between them
- [x] **4.** Accounts and login (hashed passwords, sessions)
   - [x] Email per account, password reset by email, Settings (change username, email, password)
   - [x] People identified by user id behind the scenes, so usernames can change
   - [x] Profiles: picture and banner (with a move/zoom editor), status, bio, profile popup
   - [x] Animated GIFs as picture and banner (cropped frame by frame on the server with Pillow)
- [x] **5.** Online list and "is typing…" indicator
- [x] **6.** Direct messages: private two-person channels, opened from the sidebar
   - [x] Friends: requests and a friends list (a page in the chat area, like Discord); DMs only between friends
   - [x] Online and offline people in the right column
- [x] **7.** Image and file uploads (with a preview tray, drag-and-drop and pasting)
- [x] **8.** Host it so friends can connect: live at https://chat.datslok.no through a Cloudflare Tunnel
   - [x] Before going online: invite code for new accounts, login limits, HTTPS (wss://, secure cookies)
   - [x] Mobile-friendly layout (drawers for channels and the online list)
   - [x] Separate development database (dev.db), so tests stay out of the real chat
- [x] **9.** Nice-to-haves, in this order:
   - [x] Unread dots on channels and DMs (remembered by the server)
   - [x] Message ids and times on the page, message grouping and date dividers
   - [x] Replies
   - [x] Reactions, with a full emoji picker (from Unicode's emoji list)
   - [x] Custom emoji (12 per person, also animated) as reactions
   - [x] Editing and deleting your own messages; admins can edit and delete anyone's (tools/make_admin.py)
   - [x] @mentions and @everyone (stored by user id), with a red unread count per channel
   - [x] Notifications for DMs and mentions (desktop notifications, a generated sound, count in the tab title)
   - [x] Custom emoji inside messages (typing :pog:, stored as <:id> tokens); emoji picker and jumbo emoji in messages; multi-line text box
   - [x] Desktop app via Tauri (Windows installer, real notifications, automatic updates)
- [x] **10.** Voice with WebRTC, through our own LiveKit server (self-hosted on this PC)
    - [x] LiveKit server (voice.ps1), reachable at voice.datslok.no (tunnel) with UDP/TCP forwarded on the router
    - [x] Voice tickets from our server (/voice-token: a JWT signed with the standard library)
    - [x] Lounge voice channel: join, mute, leave
    - [x] Voice settings: input and output device, mic and output volume, sensitivity (noise gate, with dB numbers)
    - [x] Noise suppression like Discord's Krisp: Off / Light (the browser's own) / On (RNNoise, an AI filter; the default)
    - [x] Volume per person (in the profile popup, 0-200%)
    - [x] Who is in voice (in the sidebar, with 🔇 for muted) and a speaking ring
    - [x] Calls in DMs: ringing on every device, accept/decline, call notes in the DM
    - [x] Call banner in the DM (both pictures with speaking rings, mute, end call, Join call)
    - [x] Sounds: calling, ringing, join and leave cues
    - [x] Voice in the desktop app
    - [x] Incoming call notifications in the desktop app
- [x] **11.** Video in calls and Lounge: camera on/off (through our LiveKit server, like voice)
    - [x] Camera button, and video in the DM call banner
    - [x] A Lounge page with a tile for everyone (video or picture)
    - [x] Choosing the camera in Settings, with a preview
    - [x] Tiles sized to fit, focus view (click a tile: big, the others as thumbnails; right-click: profile), fullscreen, and a resizable DM call banner
- [x] **12.** Screen sharing in calls and Lounge (through LiveKit, like the camera): 720p/1080p/1440p, 30/60 fps, with sound
- [x] **13.** Start the chat (serve.ps1) and voice (voice.ps1) automatically with Windows, without open windows
    - [x] Scripts to run the server on its own PC (scripts\server\: install, export, import, update; scheduled tasks; README)
    - [x] Set up on the laptop and tested (a restart brings everything back by itself)
- [x] **14.** Backups of chat.db and uploads/: nightly onto the server PC's second disk (30 days), and a copy fetched to the development PC
- [x] **15.** Everyday chat gaps, in this order:
    - [x] Clickable links in messages
    - [x] Clicking a notification goes to the message (browser and desktop app)
    - [x] F5 keeps you in the channel you were in
    - [x] Desktop app downloads: "Download this file?", a progress bar, then Explorer with the file selected
    - [x] Custom emoji: replace the picture (old messages and reactions keep working); GIFs animate in the picture editor
    - [x] A "get the Windows app" banner, and the download first in Settings
    - [x] Automatic restart of the app when a new update is available after a disconnect (and after leaving a call; release-upload.ps1 restarts the chat)
    - [x] Bugs & ideas: a form in Settings, saved on the server and emailed to the admins, an Inbox in Settings for admins (and tools/feedback.py)
    - [x] What's new in Settings (a hand-written changelog), with a red dot on ⚙️ when there's something new
    - [x] Loading older messages when scrolling up (past the newest 50)
    - [x] Text formatting: **bold**, *italic*, `code`, code blocks, > quotes, ||spoilers||, ~~strikethrough~~
    - [x] Link previews (title and picture for pasted links, fetched safely by the server)
- [x] **16.** Organising the chat
    - [x] Admins create, rename, delete and reorder channels from the app, with headings to group them (Settings → Channels)
    - [x] Group DMs (private chats with 3-10 people, with group calls)
    - [x] Pinned messages per channel (and in DMs and groups; the 📌 at the top of a chat)
    - [x] LaTeX support (maths in messages, drawn by KaTeX)
    - [x] Open on startup: the Windows app can start with Windows (Settings → App behaviour; app 0.1.16)
    - [x] Search messages (by text, person or channel; SQLite's FTS5; the 🔍 at the top of a chat)
- [x] **17.** Social and presence
    - [x] Statuses: Online, Idle (automatic when away), Do Not Disturb (no notifications), Invisible
    - [x] Muting a channel or DM (and groups; admins can't be muted: their messages always get through)
    - [x] Blocking someone (admins can't be blocked, nor bots)
    - [x] Roles with colours (coloured names and headings in the member list; Settings → Roles)
    - [x] A user menu on right-click (profile, mention, message, call, friends, mute, block), like Discord's
- [ ] **18.** Smaller polish
    - [x] Clicking a reply's quote jumps to the original message (was already there)
    - [x] Up arrow in an empty text box edits your last message (was already there)
    - [x] A "New messages" divider where you stopped reading (also for messages that came while away)
    - [x] GIF search (GIPHY; Tenor's API was shut down in June 2026): the GIF button, saved on our server when sent
    - [x] Mobile online icon (a little phone instead of the dot when someone is only on phones)
    - [x] Seasonal easter egg video (🎃 on your own picture in October; seasonal/ on the server), and a bigger picture at the bottom left
    - [x] Push-to-talk, as an alternative to the noise gate
    - [x] detect user activity (toggle in settings) games, apps running, what they are doing, listening to spotify, and so on.
    - [x] Bug: after scrolling up, sending a message doesn't scroll back down to it (sending should always jump to the bottom)
- [x] **19.** Watching together in calls
    - [x] A small floating window with the call's participants (who's talking), also while a share is in fullscreen
    - [x] A volume slider for a screen share's sound (separate from the person's voice)
    - [x] Bug: sharing a screen with YouTube on it, the share went black after tabbing out (alt-tab): the browser stops drawing a covered window (occlusion), not our code; workarounds in the README, "A shared window goes black"
- [x] **20.** Appearance (Settings → Appearance, saved with your account)
    - [x] The colours as CSS variables, so themes can change them
    - [x] Saved on the server with the account (checked there), applied before the page is drawn
    - [x] The Appearance page: themes (Dark, Darker, Light, Blue, Purple, Green, Pink, Light pink), colour pickers for the main colours, font (Windows' own), text size
    - [x] Scale, in the desktop app only (WebView2's own zoom, through a new app version; browsers have Ctrl + and Ctrl −)
- [x] **21.** The phone app (a PWA: installed from the website, no app store)
    - [x] Installable: manifest, icons (tools/make_pwa_icons.py), a service worker
    - [x] Push notifications for DMs, mentions and calls while the chat is closed (Web Push, VAPID keys), opening the message when tapped
    - [x] Polish: a banner on phones: Install (Chrome's own dialog), then Turn on notifications
- [ ] **22.** A native phone app: React Native with Expo, in `mobile/`, Android first (iPhone later from the same code)
    - [x] Setup: Android Studio and its SDK, an Expo project (JavaScript), a development build on the phone that updates live
    - [x] Log in, the channel list, and reading messages live over the WebSocket
    - [x] Writing: sending, replies, reactions, editing and deleting
    - [x] DMs, friends, unread dots and mentions
    - [x] The web chat's phone design: top bar with drawers (channels, members), messages grouped with pictures, Lucide icons
    - [x] The People page like the web's: tabs (Friends, Everyone, Requests, Blocked), Online/Offline, its buttons
    - [x] Messages like the web: formatting (bold, code, links, maths), custom emoji, link previews, the emoji picker, GIFs, typing
    - [x] Pictures and files: viewing (pinch to zoom), uploading (photos, camera, any file), downloading (open or share)
    - [x] Sharing to the app: ChatApp in Android's share sheet (from the gallery, other apps), into a chat's tray, with the files' real names (still to test with a release build: a share that starts the app, which development builds' launcher swallows)
    - [x] The chat's top bar: mute, search, pinned messages
    - [x] Profiles, the user menu (long press), your status, groups (create, add, rename, leave), invites
    - [x] Settings: my account, profile, appearance (themes, colours, text size), log out
    - [x] The rest of Settings: the web's picture editor (move and zoom; animated GIFs stay animated for pictures, banners and emoji), Emoji, What's new, Bugs & ideas, Admin (with Ban and Make admin in the user menu), the seasonal easter egg
    - [x] Voice and video calls (LiveKit's React Native library), also with the phone locked; the Lounge; Settings → Voice & audio and Video (with RNNoise and the mic volume in our own native code); the floating call window (also on the web page)
    - [ ] Push notifications through Firebase Cloud Messaging, ringing calls; Settings → Notifications
    - [ ] Distribution: the app's icon, a release signing key, the real server, an APK on the download page, and updates (expo-updates)
- [x] **23.** Chattus, an AI bot in the chat, with a language model on the server's graphics card
    - [x] A local model answering (llama.cpp's llama-server with Qwen 3.5 9B; Ollama couldn't find the GTX 1070), started at boot ("ChatApp AI", install.ps1 -AI)
    - [x] A bot account and a script that logs in and connects to the WebSocket: answers @Chattus anywhere, and everything in #chattus and in DMs to him
    - [x] The channel's recent messages as context, answers as replies, a friendly personality with short chat-sized answers (English)
    - [x] Reactions, emoji in his answers, the custom emoji by name
    - [x] Looking at pictures (and what the custom emoji show)
    - [x] Web search: Exa through its MCP server (no account; EXA_API_KEY optional), Wikipedia when Exa says no (a daily limit; "@Chattus search: ..." forces one)
    - [x] Dice and polls (the model reads what's asked; Python rolls, and posts the poll with numbers to vote with)
    - [x] On Claude Haiku 5.5 instead of the local model (a switch in .env), with Claude's own web search
    - [x] Reminders, with Claude only (the 9B model too often got the time wrong)
    - [x] Searching the chat (with Claude: older messages he can't see; only the channels and the chat he's asked in), and a "bot" badge
